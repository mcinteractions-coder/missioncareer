# Architecture rules
- Scope temporary public festival tokens to a route-aware shared wrapper, with decorative content in a dedicated component; this includes floating panels while leaving admin tools unchanged.
- Keep the static university logo catalogue as CDN asset pointers with original source URLs; avoid runtime logo services and preserve trademark artwork unchanged.- Keep study-cost figures and the budget formula in one shared module used by both the comparison and calculator pages, with tests next to it; why: both tools must show the same numbers.
